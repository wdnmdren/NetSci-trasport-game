# 动态物流网络 · PySide6 demo

## 启动（Windows / Python 3.10+）

```powershell
py -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe main.py
```

如果没有 `py`，使用本机 Python 的完整路径替换它。

先点击起点，再点击终点创建有向边，然后点击三角形开始。右键取消起点。重复连接同一方向增加平行带宽；边不可删除。初始 5 个节点、5 个边槽。边容量 = 当前节点数 + floor((当前节点数 - 初始节点数) / 3)：每新增一个节点获得一个边槽，每累计新增 3 个节点额外奖励一个边槽。旧存档读取后也使用新公式，已有边保留。

货物沿曲线运动，每个节点下方显示等待总数、各目标形状及对应数量、过载倒计时。顶部操作栏显示分数、tick、边数量；三角形用于开始，运行时切换为方形用于暂停，支持 1/2/4 倍速。新游戏、保存、读取、导出统一位于操作栏末尾的“设置”菜单中。

暂停键旁的“重新排版”使用力导向布局整理节点，再避让节点和货物标签，连线与运输动画同步跟随。布局位置写入存档，并记录 `layout_changed` 事件。生成新节点同样避让现有节点和标签，地图拥挤时会向外扩展。

鼠标滚轮以指针位置为中心缩放（15%–600%），中键拖动画面，双击地图适应全图。“重新排版”也会恢复全图视野。默认视野在新增节点后自动适应；手动缩放或拖动后保留玩家视野。

在“设置 → 语言”中选择“中文”或“English”，立即切换菜单、按钮、地图标注、统计、规则与操作提示。语言偏好保存在 `data/preferences.json`，下次启动自动沿用，与游戏存档独立。

## 数据和存档

- `data/research.sqlite`：所有局的会话、初始完整状态、事件、每 tick 队列/路由/边使用率与每 20 tick 快照。
- `data/autosave.json`：每 20 tick 自动保存。
- `data/last_session.json`：正常退出保存，可通过“读取”打开。
- “保存”写入完整状态和随机生成器状态；“读取”暂停恢复并创建独立研究会话。
- “导出本局 CSV”输出当前会话事件，`data_json` 包含结构化详情。历史会话保留在 SQLite 中。

模拟先同步完成一个 tick，再播放该 tick 的视觉插值；保存的是完整模拟边界，读取时不会播放保存前的未完动画。建边会结束当前动画显示。每件货物最多跨越一条边/tick。路由按跳数 BFS，等长路径按节点 ID 字典序选择，FIFO 支持跳过暂时无法运输的货物。

演示参数：固定种子 42；每 25 tick 新增节点；每 tick 生成 `1 + tick // 60` 件货物；队列超过 12 连续 12 tick 失败。参数目前位于 `core.py`，尚未提供设置页、回放和历史浏览界面。无云端依赖。
